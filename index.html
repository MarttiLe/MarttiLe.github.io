Frame · Case Study / 03


        

          

            
Case study · this page

            
Designing my own portfolio.

            
How this site came together — the brief, the constraints, the decisions, and what I'd do differently next time.

          

          

            
3h
Wireframes

            
12h
Build

            
100%
Hand-coded

          

        


        


          
          

            
01

            

              
The problem

              
Dev portfolios mostly look the same: a CV in HTML, list of skills with progress bars, "contact me" form. Recruiters skim and forget. I needed something they'd remember — and that proved I can build, not just describe.

            

          


          
          

            
02

            

              
Goals & constraints

              

                Memorable type system
                Editorial, not template-y
                Proof > promises (live demos)
                Recruiter-scannable in 20s
                Mobile + dark mode from day one
                Zero frameworks · hand-coded
              

            

          


          
          

            
03

            

              
Design decisions

              

                

                  
Instrument Serif · italic

                  
For display type. Signals editorial taste, not "another dev portfolio." Paired with Geist sans for body and JetBrains Mono for labels.

                

                

                  
Emerald, not corporate blue

                  
One bold accent in OKLCH. Distinct from the typical Tailwind-default palette every other dev portfolio uses.

                

                

                  
Bento layout

                  
Modular tiles instead of long scroll. Scans well, allows visual hierarchy without forcing a single reading order.

                

                

                  
Live demos, not screenshots

                  
Color Studio + Doggo Select are both working. Recruiters interact instead of read — instant proof.

                

              

            

          


          
          

            
04

            

              
What's in production

              

                
Bento hero · responsive 12-col grid

                
Live status strip with rotating role typewriter

                
Featured case study (RaeKoss) with live mShots preview

                
Two interactive demos — pure vanilla JS

                
Figma-style design system + wireframes (this frame)

                
Light + dark theme · OKLCH color system

                
Command palette (press /)

                
Open Graph + JSON-LD for rich previews

                
A4 print-ready CV in the same system

              

            

          


          
          

            
05

            

              
Takeaways

              
    
                
  • Editorial typography wins attention faster than gradients ever will.
    • 
                
  • One interactive demo beats five static screenshots.
    • 
                
  • Design systems aren't just for big teams — they keep solo work consistent and fast to iterate.
